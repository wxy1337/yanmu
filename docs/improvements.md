# 第一批改进记录

本批覆盖可靠性修复、任务管理、字幕预览和基础校对。高级翻译与配音功能继续按阶段推进。

## 已完成

- 移除字幕统一截断到 5 秒的行为，保留识别结束时间。
- 识别结果和逐批译文原子保存到任务目录的 `segments.json`。
- HTTP 408、429、5xx、网络错误和不完整译文有限重试；身份验证等永久错误直接报告。
- 失败或取消后点击“继续重试”，复用识别结果和已完成译文。
- 服务重启后将中断任务标为可重试，保留源文件和检查点。
- 增加任务取消、删除及队列上限；删除前要求任务完全停止。
- 上传接收阶段限制请求大小，上传前检查磁盘余量；界面上传限制跟随后端配置。
- FFmpeg 支持超时和取消；识别在模型调用返回/字幕片段之间检查取消。
- 模型缓存仅保留最近加载模型；正在运行的任务仍持有必要引用。
- 新配置默认仅监听本机；Docker 默认仅发布到宿主机的 127.0.0.1。
- 增加跨站修改请求检查，明确说明外部翻译的数据发送行为。
- Distil Large v3 必须明确选择英语，前后端均校验。
- 新任务导出 SRT、ASS、VTT；非压制模式在浏览器加载字幕轨道。
- 基础校对界面：修改原文、译文和时间，点击字幕编号跳转播放。
- 编辑校验时间范围及文本长度，并用版本校验防止两个页面互相覆盖。
- 保存后更新字幕、撤下旧成片链接，可用已有字幕重新压制。

## 使用方法

1. 更新后重启服务，并刷新浏览器。
2. 失败或取消的任务点击“继续重试”；处理中的任务可点击“取消任务”。
3. 完成后打开任务，点击“校对字幕”，修改内容后保存。
4. 需要成片时点击“重新压制视频”；这一步不重新识别。
5. “删除文件”会删除该任务的上传文件、字幕和成片，页面会先确认。

## 新配置

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| APP_HOST | 127.0.0.1 | 直接启动时的监听地址 |
| MAX_PENDING_JOBS | 20 | 同一进程内排队和执行中的任务总上限 |
| MIN_FREE_DISK_MB | 1024 | 上传后要求保留的磁盘余量，不包含未来成片估算 |
| MEDIA_TIMEOUT_SECONDS | 14400 | 单次媒体子进程的最长处理时间 |
| TRANSLATION_RETRIES | 2 | 首次请求失败后最多额外重试次数 |

已有 `.env` 不会被覆盖；如果其中仍是 `APP_HOST=0.0.0.0`，仅本机使用时改为 `APP_HOST=127.0.0.1`。
Docker 容器内部监听所有接口，但宿主机端口只绑定本机。共享部署仍应配置带认证的反向代理。

## 边界与兼容性

- 旧任务在本次更新前没有保存 `segments.json`，首次重试可能需要重新识别；旧的已完成任务需重新生成才能使用校对功能。
- 模型下载、单次识别推理和正在进行的 HTTP 请求不能强制安全中断；取消会在调用返回或请求超时后完成。FFmpeg 可主动终止。
- 任务存储和执行队列目前设计为单进程；不要启用多个 Uvicorn worker 共享任务目录。
- 浏览器预览依赖原视频的编码支持；部分 MKV/AVI 等需要压制成 MP4 后预览。
- 保留长字幕时间是正确性修复，词级智能切分、阅读速度与重叠提示还需进一步完善。
- 临时磁盘空间与并发上传仍可能影响可用空间；本批未加入自动清理，避免自动删除用户文件。
- 不提供用户账户隔离，默认本机访问不等同于共享部署身份验证。
